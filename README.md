# 📄 MeuCurrículo.ai - Gerador de Currículo com IA

Um gerador de currículos em tempo real com exportação para PDF e assistência de IA integrado usando Tailwind CSS, html2pdf.js e a API do Gemini.

## 🚀 Funcionalidades

- **Edição em Tempo Real:** Pré-visualização instantânea das alterações em layout padrão A4.
- **Suporte a IA:** Geração assistida de resumos e experiências profissionais.
- **Exportação em PDF:** Baixe seu currículo pronto para envio em um clique.
- **Design Responsivo:** Interface limpa construída com Tailwind CSS.

## 🛠️ Tecnologias Utilizadas

- HTML5 / CSS3 / JavaScript Moderno
- [Tailwind CSS](https://tailwindcss.com/)
- [Phosphor Icons](https://phosphoricons.com/)
- [html2pdf.js](https://ekoopmans.github.io/html2pdf.js/)
- Google Gemini API
